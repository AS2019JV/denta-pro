## Additional contract differences absent from older fields

`column-contract-differences.json` compares matching public column attributes exactly. It includes views and column ACL, so do not call its total a count of base schema type changes. Newly visible exact base type differences:

- clinics.size: production character varying(50); staging character varying.
- payments.amount: production numeric(10,2); staging numeric.
- services.price: production numeric(10,2); staging numeric.

Six existing clinic_id nullability changes remain intentionally hardened in staging. Staging retains data_rights_requests.resolution_notes. Production has authenticated UPDATE column ACLs on eight profiles columns that staging lacks. Relation ACLs must be reviewed separately; a missing column ACL does not mean no table-level access.

profile_audit_log_id_seq is referenced by the default in both environments, but production owns it by public.profile_audit_log.id and staging has no OWNED BY dependency. logs.access_audit.id is GENERATED BY DEFAULT AS IDENTITY in both. Sequence int64 bounds are serialized as strings to preserve exact values.

## Reconstruction boundary

Managed Auth/Storage/Realtime schema definitions, roles with passwords, settings/secrets, full Supabase service configuration, row data, live sequence values, Storage bytes, all database-level objects and a restore ordering archive are not captured. PL/pgSQL dynamic/string body dependencies may not appear in pg_depend; bodies require review and real execution. Snapshot generation is not equivalent to pg_dump's dependency-aware consistent archive.

A reviewed local reconstruction can prove clean install and synthetic upgrade convergence **for the declared contract scope**. It cannot prove full remote clone upgrade, restore/DR, or remote JWT/provider configuration. M7 remains NOT READY. Default public ACLs observed remotely are broad; retain them as evidence but do not automatically replay them into a client-accessible local final baseline. Every deliberate ACL/owner/policy/type/function variation needs a decision and verification.
