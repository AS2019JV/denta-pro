Antes de COMMIT, timeout/error/postcondición implica rollback atómico. Si se pierde conexión en COMMIT: resultado incierto; capturar estado y reconciliar, sin reintento ciego. Después de COMMIT, mantener escritores detenidos hasta postchecks; no ejecutar down migrations. Tras nuevas escrituras confirmadas, el backup anterior pierde esas escrituras: requiere copia nueva coherente o reconciliación auditada. El ensayo posterior captura una copia nueva tras escrituras conocidas y verifica recuperación completa; no demuestra que restaurar el baseline las conserve. No restaurar sobre el proyecto origen ni borrar sus volúmenes. Gate4 de producción y recuperación operativa alojada siguen pendientes.
